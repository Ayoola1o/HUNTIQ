# Another important issue: auth fallback

The latest auth middleware still has a development fallback that creates a user context when there isn't a valid token. The same update also introduced the new JWT authentication system. 

That's okay for local development, but production must behave differently:

```text
PRODUCTION
missing/invalid auth
        ↓
401 Unauthorized
```

not:

```text
missing auth
   ↓
development user
   ↓
request allowed
```
